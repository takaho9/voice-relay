voice-relay

スマホで入力した（話した）テキストを、暗号化してこの PC に届けます。

秘密はこのブラウザの中だけで作られ、どこにも送信・保存されません。 このページを再読み込みすると別のペアに作り直されるので、手順 1〜2 はこの画面のまま進めてください。

1スマホで QR コードを読み取る

開いたページをホーム画面に追加（またはブックマーク）してください。次回からはそこから送れます。

確認コード — スマホの画面右上にも同じコードが出ていれば OK です。

QR コードが読み取れないとき

次の URL をスマホで開いてください（この URL を知っている人はあなたにメッセージを送れるので、他人に見せないでください）。

2この PC での受け取り方を選ぶ

A. ターミナルで常駐させる（おすすめ・Linux）

届いたら自動でクリップボードにコピーされ、通知が出ます。Ctrl+V で貼り付けるだけです。次回からはログインするだけで動きます。

  1. ターミナルで次のコマンドを実行します。

    python3 -m pip install --user --upgrade "cryptography>=50.0.2"
git clone https://github.com/takaho9/voice-relay.git ~/voice-relay
python3 ~/voice-relay/cli/voice_relay.py service install

  2. ターミナルが受信用 URL の貼り付けを求めたら、このボタンを押し、ターミナルに貼り付けて Enter（貼り付けた内容は画面に表示されません）。

X11 の環境で Ctrl+V も省きたい場合は、最後の行を … service install --type にすると、フォーカス中の入力欄に直接貼り付けます（改行は空白にし、Enter は押しません。端末には入力しません）。

受信用 URL を表示

この URL を知っている人は、あなた宛てのメッセージを読むことも、偽のメッセージを送ることもできます。 共有 PC のファイルやチャットに残さないでください。

B. このブラウザで受け取る（インストールなし）

届いたテキストがこのタブに表示されるので、「コピー」を押して貼り付けます。

秘密はブラウザに保存されないので、次回は受信ページに受信用 URL の貼り付けが必要です。

3スマホから送ってみる

スマホで話します（入力が止まると自動で送信されます。画面上部で「手動送信」に切り替えることもできます）。PC に届けば完了です。A を選んだ場合、このページはもう閉じて構いません。

パスワードなどの機密は送らないでください。試験中など外部との通信が禁止されている場面では使わないでください。
