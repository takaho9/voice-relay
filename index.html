voice-relay セットアップ

スマホで入力したテキストを、暗号化してこの PC（または別の PC）に届けます。 秘密はこのブラウザの中だけで生成され、どこにも送信・保存されません。

1. スマホで送信ページを開く

スマホのカメラでこの QR コードを読み取り、開いたページをブックマークかホーム画面に追加してください。

確認コード: （送信・受信ページにも同じコードが表示されます）

送信ページの URL を表示

2. 受信する

ブラウザで受信する場合:

秘密は受信ページに一度だけ引き継がれ、ブラウザには保存されません。受信ページをリロードしたときは、下の「受信用 URL」の貼り付けが必要です。

ターミナルで受信する場合（Node.js 20 以上）:

リポジトリを clone して node cli/voice-relay.mjs import を実行し、 下の「受信用 URL」を貼り付けてください。以後は node cli/voice-relay.mjs receive で受信できます。

受信用 URL を表示（別の PC で受信する場合など）

この URL を知っている人は、あなた宛てのメッセージを読むことも、偽のメッセージを送ることもできます。 共有 PC のファイルやチャットに残さないでください。

設定

作り直すと、以前の送信ページ（ブックマーク）は使えなくなります。
